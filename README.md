## Пошаговая инструкция

### Шаг 1. Один раз: постоянный ключ подписи (5 минут)

Ключ подписи — это «печать» приложения. Если она каждый раз новая, Android
не даст обновить приложение поверх старого, и придётся удалять его **вместе
со всей перепиской**. Поэтому один раз кладём постоянный ключ в GitHub.

1. Открой https://github.com/Iluxy01/massanger2/settings/secrets/actions
2. Нажми **New repository secret**.
   - **Name:** `KEYSTORE_BASE64`
   - **Secret:** всё содержимое файла `KEYSTORE_BASE64.txt` (одна длинная строка)
   - **Add secret**
3. Ещё раз **New repository secret**.
   - **Name:** `KEYSTORE_PASSWORD`
   - **Secret:** содержимое файла `KEYSTORE_PASSWORD.txt`
   - **Add secret**
4. Сохрани оба файла и `veil.jks` где-нибудь у себя (например, в облаке).
   Если их потерять, при следующем обновлении придётся переустановить
   приложение. **Никому не отправляй эти файлы и не клади их в репозиторий.**

> Хочешь сделать ключ сам? См. раздел «Свой ключ подписи» внизу.

### Шаг 2. Собрать APK

1. Открой https://github.com/Iluxy01/massanger2/actions/workflows/build-apk.yml
2. Справа нажми **Run workflow**, выбери ветку `claude/secure-messenger-android-dujwud` и снова **Run workflow**.
3. Через 5–8 минут появится зелёная галочка ✅. Открой этот запуск,
   внизу в разделе **Artifacts** скачай **veil-apk**, распакуй — внутри `veil.apk`.

### Шаг 3. Установить на свой телефон и на телефон друга

1. **Если стояла старая версия Veil — удали её** (она подписана другим ключом и
   была демо-версией, там нечего терять). Дальше обновления будут ставиться поверх.
2. Перекинь `veil.apk` на телефон и открой его → разреши установку → «Установить».
3. Отправь тот же `veil.apk` другу (например, через Telegram) — он делает то же самое.

### Шаг 4. Первый запуск

1. Пролистай приветствие, введи имя, выбери эмодзи и цвет → **Сгенерировать ключи**.
2. Разреши **уведомления**, когда Android спросит.
3. Зайди в **Профиль → Сеть**: там должно быть «Подключено: N из 5» с зелёной точкой.

### Шаг 5. Добавить друга

**Если вы рядом:** у друга **Друзья → Добавить друга → Мой код**,
у тебя **Друзья → Добавить друга → Сканировать** → наведи камеру на его QR.

**Если вы далеко:** друг жмёт **Друзья → Пригласить друга по ссылке** и шлёт
тебе сообщение (через любой мессенджер). Ты копируешь это сообщение целиком →
**Друзья → Добавить друга → Сканировать → Вставить код**.

Тот, кого добавили, увидит тебя в чатах с пометкой-заявкой: можно **Принять**
или **Заблокировать**. Всё — пишите!

### Шаг 6. Чтобы уведомления приходили, когда приложение закрыто

Veil без серверов и без Google-пушей, поэтому в закрытом состоянии он
проверяет почту сам — примерно **раз в 15 минут** (чаще Android не разрешает).
Когда приложение открыто, сообщения приходят мгновенно.

Многие телефоны (Xiaomi, Huawei, Honor, Samsung, Realme) «усыпляют» фоновые
задачи. Чтобы этого не было:
- **Настройки → Приложения → Veil → Батарея → Без ограничений**;
- на Xiaomi ещё: **Автозапуск → включить**.

### Шаг 7. Как обновлять

Когда я что-то меняю, GitHub сам собирает новый APK (шаг 2, только кнопку жать
не нужно — запуск появится сам). Скачиваешь и ставишь **поверх**, ничего не
удаляя: переписка сохранится.

## Как это устроено и почему это бесплатно

```
 Твой телефон                     Ретрансляторы Nostr               Телефон друга
 ┌──────────────┐  зашифрованный   ┌──────────────────┐  забирает   ┌──────────────┐
 │ ключи        │──── конверт ───▶ │ relay.damus.io   │ ─────────▶  │ расшифровывает│
 │ база (AES)   │                  │ nos.lol  … (5 шт)│             │ сохраняет у  │
 │ переписка    │ ◀── отчёт ────── │ хранят ≤ 7 дней  │ ◀────────── │ себя         │
 └──────────────┘                  └──────────────────┘             └──────────────┘
```

- **Никакого своего сервера.** Сообщения идут через публичные бесплатные
  ретрансляторы сети Nostr (их сотни, их держат энтузиасты). Нам не нужен ни
  хостинг, ни аккаунты, ни карта — поэтому Veil бесплатен навсегда.
- **Ретранслятор ничего не знает.** Каждое сообщение упаковано в тройной
  конверт ([NIP-59](https://github.com/nostr-protocol/nips/blob/master/59.md)):
  снаружи — одноразовый ключ и случайное время, внутри — шифр
  [NIP-44](https://github.com/nostr-protocol/nips/blob/master/44.md)
  (ChaCha20 + HMAC-SHA256). Видно только «кому», но не «от кого» и не «что».
- **Хранится только у вас.** Ретранслятор держит конверт, пока друг не в сети,
  и удаляет его через 7 дней. Сама переписка — только в базе на телефонах,
  зашифрованной AES-256-GCM ключом из Android Keystore.
- **Без номера телефона.** Твой адрес — это публичный ключ. Познакомиться можно
  только обменявшись кодами.
- **Надёжность.** Сообщение отправляется сразу в 5 ретрансляторов: достаточно,
  чтобы работал хотя бы один. Если связи нет — оно ждёт в очереди и уйдёт само.
  В **Профиль → Сеть** можно добавить любой другой ретранслятор.

**Честные ограничения:** уведомления в закрытом приложении — с задержкой до
~15 минут; голосовые, фото и звонки пока не реализованы; переписка не
переносится на новый телефон автоматически (будет экспорт).

## Что уже есть

**Онбординг**
- 3 слайда с параллаксом и «орбитами» из эмодзи вокруг светящегося шара
- создание профиля без телефона и почты: имя, эмодзи-аватар, цвет
- анимация генерации ключей: символы «проявляются» в отпечаток ключа

**Чаты**
- живой фон «северное сияние», стеклянные панели с размытием
- лента друзей «в сети» с вращающимися градиентными кольцами и пульсирующими точками
- свайп вправо — закрепить, влево — удалить; долгое нажатие — быстрые действия
- «печатает…» с прыгающими точками прямо в списке, черновики, счётчики непрочитанного
- всплывающее стеклянное уведомление о новом сообщении (смахивается вверх)

**Переписка**
- градиентные пузыри с «хвостиками», группировка, даты-разделители
- галочки статуса: ⏱ → ✓ → ✓✓ → ✓✓ цветные (анимированные)
- **свайп вправо по сообщению — ответить** (с вибро-откликом)
- **двойной тап — ❤️** с разлетающимися сердечками
- **долгое нажатие** — фон размывается, появляются реакции и меню
- **секретные сообщения** 👁: размыты, пока не коснёшься; входящие прячутся обратно через 8 сек
- «печатает…» и «в сети» — настоящие, от друга (если он не выключил их в настройках)
- 1–3 эмодзи в сообщении показываются крупно и «покачиваются»
- меню вложений, кнопка «вниз» со счётчиком новых сообщений

**Друзья и безопасность**
- добавление друга по QR-коду камерой или по ссылке-приглашению (конфетти 🎉)
- код безопасности: 60 цифр + визуальный «отпечаток», отметка «проверен»
- исчезающие сообщения (настройка на чат), блокировка, очистка переписки
- PIN-код с клавиатурой из стекла, тряской при ошибке и автоблокировкой при сворачивании
- запрет скриншотов, отключаемый текст в уведомлениях
- «красная кнопка»: удерживай, чтобы стереть всё с устройства

**Оформление**
- тёмная и светлая тема, 6 акцентных палитр — меняют весь интерфейс на лету
- вибро-отклик почти на каждое действие (можно выключить)

### Собрать самому на Windows (необязательно)

Понадобится один раз установить инструменты (~10 ГБ места, ~30–40 минут).

1. **Git** — https://git-scm.com/download/win (все галочки по умолчанию).
2. **Android Studio** — https://developer.android.com/studio
   При первом запуске выбери *Standard*, дождись загрузки SDK.
   Затем *More Actions → SDK Manager → SDK Tools* → отметь
   **Android SDK Command-line Tools** → *Apply*.
3. **Flutter** — https://docs.flutter.dev/get-started/install/windows/mobile
   Скачай zip, распакуй в `C:\src\flutter` (не в `Program Files`!).
   Добавь `C:\src\flutter\bin` в PATH:
   *Пуск → «Изменение системных переменных среды» → Переменные среды → Path → Изменить → Создать*.
4. Открой **новое** окно PowerShell и выполни:
   ```powershell
   flutter doctor --android-licenses   # на все вопросы отвечай y
   flutter doctor                      # должны быть зелёные галочки у Flutter и Android toolchain
   ```
5. Скачай проект и собери APK:
   ```powershell
   cd C:\src
   git clone https://github.com/iluxy01/massanger2.git
   cd massanger2
   git checkout claude/secure-messenger-android-dujwud
   flutter pub get
   flutter build apk --release
   ```
   Готовый файл: `build\app\outputs\flutter-apk\app-release.apk`.

**Запуск прямо на телефоне по кабелю** (удобно, когда что-то меняешь):
на телефоне включи *Настройки → О телефоне → 7 раз тапни «Номер сборки»*,
затем *Для разработчиков → Отладка по USB*. Подключи кабель и выполни
`flutter run` — изменения кода подхватываются на лету клавишей `r`.

### Посмотреть демо в браузере

```powershell
flutter run -d edge --dart-define=DEMO=true
```
В браузере всегда включается демо-режим с выдуманными друзьями (настоящая сеть работает только на Android).

## Свой ключ подписи (если не хочешь использовать готовый)

1. В PowerShell (keytool идёт вместе с Android Studio):
   ```powershell
   & "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkey -v `
     -keystore veil.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. Превратить в текст: 
   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("veil.jks")) | Set-Clipboard
   ```
3. Вставить в секреты `KEYSTORE_BASE64` и `KEYSTORE_PASSWORD`, как в шаге 1.

## Структура проекта

```
lib/
  main.dart                 запуск: база, сеть, фоновая проверка
  app.dart                  тема, экран блокировки, всплывающие уведомления
  core/
    nostr.dart              ключи secp256k1, подписи BIP-340, события
    nip44.dart              шифрование NIP-44 v2
    giftwrap.dart           тройной конверт NIP-59
    protocol.dart           что лежит внутри конверта, ссылки-приглашения
    relay_pool.dart         соединения с ретрансляторами, очередь, переподключение
    store.dart              база SQLite + AES-256-GCM, секреты в Keystore
    notifier.dart           системные уведомления
    background.dart         фоновая проверка раз в ~15 минут
  state/
    app_state.dart          состояние для экранов (+ демо-режим)
    live.dart               «живой» режим: связывает сеть, базу и экраны
    mock_data.dart          демо-друзья для скриншотов
  models/ theme/ widgets/ screens/   интерфейс
test/
  nip44_test.dart           официальные тест-векторы шифрования
  live_test.dart            два «телефона» переписываются через тестовый ретранслятор
  network_test.dart         проверка настоящих ретрансляторов (в GitHub Actions)
```
